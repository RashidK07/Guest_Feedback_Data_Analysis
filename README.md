# 🏨 Guest Feedback Data Analysis using Excel

An interactive **Excel-based data analysis project** focused on understanding guest feedback, satisfaction levels, and service quality through charts, pivot tables, and trend analysis.

The project transforms raw guest feedback data into meaningful insights that can help identify **guest preferences, satisfaction patterns, service strengths, and areas requiring improvement**.

---

## 🎯 Project Objective

The objective of this project is to analyze guest feedback data and answer key business questions related to:

- Guest purpose of stay
- Gender distribution
- Net Promoter Score (NPS) categories
- Overall experience across hotel service areas
- Guest satisfaction by purpose of stay
- Rating trends over time
- Feedback quality across different rating ranges

The analysis was performed entirely using **Microsoft Excel**.

---

## 📊 What This Project Analyzes

### 1. Guest Purpose Analysis
A column chart and pivot table are used to understand the number of guests visiting for:

- Business
- Vacation
- Function

This helps identify the dominant purpose of guest visits.

### 2. Gender Distribution
A pie chart visualizes the percentage distribution of guests by gender.

### 3. NPS Category Analysis
Guest responses are categorized into:

- 🟢 Promoters
- 🟡 Passives
- 🔴 Detractors

The analysis identifies the proportion of guests in each category.

### 4. Overall Experience by Feedback Category
The project compares average **Overall Experience** scores across:

- Staff
- Room
- Restaurant
- Facility

This helps identify which areas contribute most positively to the guest experience.

### 5. NPS Analysis by Guest Purpose
Pivot tables and charts are used to compare average NPS ratings across different purposes of stay.

### 6. Rating Trends Over Time
A line chart tracks NPS ratings across years using the guest's checkout date.

A trend line is included to understand the overall direction of guest satisfaction over time.

### 7. Feedback Quality by Rating Range
The project analyzes rating ranges from **1–5** across different feedback categories to identify patterns in positive and negative feedback.
